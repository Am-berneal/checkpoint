Briefing // before you play

Three ways to fight noise

This game is about the first one.

This game

Detection

Ancilla checks flag errors they can see. Flagged shots are thrown away; the state is not repaired.

Mitigation

Hardware stays noisy. The estimate is corrected afterwards using extra circuits and shots.

Correction

Errors are decoded and undone during the computation, using many physical qubits per logical qubit.

Detection never fixes errors, and it misses any error its checks do not cover. Keeping fewer shots is the price you pay for cleaner ones.

Rulebook // game rule → physics

How the game maps to the physics

Game rulePhysics
Ancilla budgetSpace overhead of the spacetime code: one ancilla qubit per check.
Placing a checkCoherent Pauli check: ancilla in |+⟩, controlled-P before a circuit segment, controlled-P′ = U P U† after it, ancilla read in the X basis.
Discarded shotsPost-selection on a non-trivial syndrome.
T wallT is diagonal, so only I or Z commute through it. An X or Y check across a T gate would change the computation.
Checks must commuteOverlapping checks that anti-commute disturb each other's syndrome.
Shots keptSampling overhead = 1 / kept fraction.
ScoreEstimation error at a fixed shot budget N: (1 − post-selected fidelity) + 1/√(N · kept fraction). Points = 1000 × best error ÷ your error.
Limitations
  • Detection does not repair errors; it only discards shots.
  • A check only sees errors that anti-commute with it; others reach the kept shots undetected.
  • qiskit-paulice accepts Clifford circuits only, so T-doped missions use hand-built checks that obey the T-wall rule.
  • Results come from Qiskit Aer with a synthetic depolarizing noise model. On today's IBM hardware T is a virtual rz(π/4); its error rate here is a model assumption reflecting the fault-tolerant setting.
